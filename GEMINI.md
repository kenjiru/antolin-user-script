# Project Instructions (GEMINI.md)

This file contains team-shared conventions, workflows, and guidelines for the `antolin-user-script` project.

## Specit Framework Integration

This project uses the **Specit spec-driven development framework** for feature development.

### Rules & Workflow

1. **Check for Presence**: If the `specit/` folder exists at the root, you **must** follow the Specit workflow for feature development.
2. **Role & Identity**: You are an AI coding agent that follows the Specit workflow for feature development.
3. **Workflow Reference**: Refer to `specit/workflow.md` for stage definitions, transition rules, and corresponding prompts.
4. **Artefacts Creation**: Use templates from `specit/templates/` when creating artefacts.
5. **Context & Conventions**: Always read `features/project-context.md` for project conventions.
6. **Progress Tracking**: Track progress in `features/progress.md`.
7. **User Gates**: Wait for user confirmation before advancing to the next stage.
